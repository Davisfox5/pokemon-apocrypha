# Johto standard stairs

Owner-locked 2026-11-20 (Route 32 thread): north-south and east-west flights in HGSS's plank style with a rail each side.
Generated by `tools/gba/maps/johto_stairs.py`; route assemblers call its `north_south()` / `east_west()` directly.

| Piece | Size | Use |
| --- | --- | --- |
| `ns-top-west/middle/east.png` | 16 x 16 | First row of a north-south flight (starts 3 px down, level with the cliff top). A half flight is this row alone. |
| `ns-lower-west/middle/east.png` | 16 x 16 | Second row of a full north-south flight. |
| `ew-falls-east.png` | 16 x 80 | One column (one level) of an east-west flight falling east. Row 16 = top of the flight's first cell. Upper layer, over unbroken cliff. |
| `ew-falls-west.png` | 16 x 80 | Exact mirror of `ew-falls-east.png`. |

A flight n cells wide is west, middle x (n - 2), east. A full east-west flight is two columns, the lower one a row
further south. Pieces are drawn at stripe phase 0; on a map the 5 px plank cycle is counted in map pixels.
`preview.png`, left to right: north-south full and half, east-west full falling east and west, east-west half falling east and west (2x).
