# October 10 local native Johto revision

The owner rejected the cloud cohesion artwork: incomplete trees, stray pieces,
and houses/encounter grass that were flattened HGSS renders. This revision keeps
the cloud draft and earlier proposals intact and rebuilds those asset families
at native GBA resolution. It is a visual review proposal, not owner acceptance.

## Changed artwork

- Native timber houses with symmetric roof courses, continuous eaves, framed
  windows, siding, thresholds and doors aligned with their existing warp cells.
- A purpose-built 208×80 Elm institute, raised central roof monitor, glazed
  entrance, research emblem and four southern staff homes on connected streets.
- Complete 40×48 tree silhouettes using Cherrygrove's exact existing palette;
  atomic canopies and explicit small foliage modules fill narrow forest edges.
- Native 16×16 grass blade clusters and adjoining edge masks, using the HGSS
  `egrass` color ladder. These are authored pixels, not a DS texture flattening.
- Native windmills/mailboxes, orange flower clusters and rock face/terrace/cave modules. Route 31 keeps
  its measured HGSS landform silhouette, pond, crossing and gate placement.

Architecture, grass and tree pixels are defined in
`tools/gba/maps/johto_native_refinement/art.py`. No screenshot pixels enter those
three families. Paths, flowers, sea, signs, ledges and some smaller route props
reuse existing Cherrygrove/route assets. Original regional references and their
artwork remain credited to Game Freak / Nintendo / Creatures. The native redraws
are agent-authored derivatives, retaining the original Johto reference direction.

## Reproduction

Prepare `tools/gba/portable.py --preset workbench` into a fresh directory. Apply
`gba/claude-cherrygrove.patch` then `gba/claude-routes.patch` with binary patch
support and `core.autocrlf=false`. This is the routes baseline. Apply
`gba/johto-native-refinement.patch` instead of the cloud cohesion patch.
Alternatively run the native generator on the clean routes baseline:

```sh
python3 tools/gba/maps/johto_native_refinement/build.py ENGINE
python3 tools/gba/maps/johto_native_refinement/check.py ENGINE
```

Compile host tools, generate maps serially, then compile the ROM:

```sh
gmake -C ENGINE -j8 tools
gmake -C ENGINE -j1 TOOLCHAIN=TOOLCHAIN generated
gmake -C ENGINE -j8 TOOLCHAIN=TOOLCHAIN
MGBA_FLAGS='-I/opt/homebrew/include -L/opt/homebrew/lib -lmgba' \
  python3 tools/gba/maps/johto_native_refinement/runtime.py ENGINE OUTPUT \
  --toolchain TOOLCHAIN
```

This remains exterior art work. Interiors are the borrowed GBA rooms already in
the cloud proposal. Windmills and freshwater pond are static; coastal sea retains
its animation. Route 29's gate and the Route 30 houses retain their existing
closed behavior. Full Violet, full Dark Cave, campaign actors and dialogue are
not completed by this patch. Production `game/` and owner ROM/save files are untouched.
